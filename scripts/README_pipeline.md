# Reproducibility Scripts

This directory contains the public-facing analysis scripts for the manuscript revision. The scripts are organized into three groups:

1. Cohort preprocessing and integration
2. Model training, optimization, and biomarker interpretation
3. Revision-specific validation and source-data plotting

All scripts use paths relative to the package/project root. No personal local paths are required.

## Expected Raw Data Layout

Raw public datasets should be downloaded from their original repositories and placed under `data/` using the following layout:

```text
data/
  TCGA_LUAD/
    TCGA.LUAD.sampleMap_LUAD_clinicalMatrix
    survival_LUAD_survival.txt
    mc3_LUAD_mc3.txt.gz
    TCGA.LUAD.sampleMap_HiSeqV2.gz

  oncoSG/
    luad_oncosg_2020/
      data_expression_median.txt
      data_mutations.txt
    luad_oncosg_2020_clinical_data.tsv

  GSE31210/
    GSE31210_series_matrix.txt.gz
    GPL570.annot.gz

  GSE13213/
    GSE13213_series_matrix.txt.gz
    GSE13213_AD117_patient_info.txt
    GPL6480.annot.gz
```

The MSigDB Hallmark GMT file should be placed at the project root:

```text
h.all.v2025.1.Hs.symbols.gmt
```

## 1. Cohort Preprocessing and Cleaning

Run these scripts first to build the integrated EGFR-mutant LUAD cohort:

```bash
python scripts/01_preprocess_tcga.py
python scripts/02_preprocess_oncosg.py
python scripts/03_preprocess_gse31210.py
python scripts/04_integrate_and_filter.py
```

Outputs are written to:

```text
intermediate_data/
```

Key output:

```text
intermediate_data/LUAD_EGFR_mut_3_datasets_integrated_FINAL.csv
```

## 2. Model Training and Optimization

Train the XGBoost and Random Survival Forest models using the integrated EGFR-mutant cohort:

```bash
python scripts/05_train_models.py
```

This script performs:

- feature construction from clinical variables and genes in selected Hallmark pathways;
- 8:1:1 train/validation/test split;
- standard scaling;
- Bayesian hyperparameter optimization;
- final model fitting;
- feature-importance export.

Outputs are written to:

```text
results/model/
```

## 3. Model Interpretation

Decode RSF permutation importance:

```bash
python scripts/06_decode_rsf_importance.py
```

Run biomarker-level Cox regression and enrichment analysis:

```bash
python scripts/07_biomarker_cox_enrichment.py
```

Note: enrichment analysis uses `gseapy` and may require internet access to query Enrichr unless local gene-set libraries are configured.

## 4. External Validation

Run GSE13213 validation, including the EGFR-mutant subset requested during revision:

```bash
python scripts/08_external_validation_gse13213.py
```

Outputs are written to:

```text
results/analysis/GSE13213_validation/
```

## 5. 13-gene Signature and Revision Analyses

Calculate a locked 13-gene score for any compatible expression matrix:

```bash
python scripts/calculate_13gene_score.py \
  --expression path/to/expression_matrix.csv \
  --out path/to/locked13_scores.csv
```

Replot model-performance confidence-interval figures from the included source-data tables:

```bash
python scripts/plot_model_performance_ci.py
```

Additional revision-analysis scripts are included for transparency:

```text
09_13gene_convergence_analysis.py
09a_restore_original_feature_matrix.py
09b_13gene_stage_association.py
09h_plot_13gene_stage_rank_distribution.py
10_add_risk_tables_to_km.py
```

These scripts document the analyses used to quantify the locked 13-gene module and add number-at-risk tables. Some of them require processed matrices or model outputs generated by the earlier pipeline steps.

## Recommended Public Repository Contents

For public release, include:

- this `scripts/` directory;
- `data/locked_13gene_signature.csv`;
- `data/supplementary_table_s2_locked_xgboost_features.csv`;
- source-data tables for revised figures;
- `requirements.txt`;
- `README.md`;
- `docs/data_availability_statement.md`.

Do not include private raw patient-level data, local working logs, or historical exploratory retraining attempts.
