# Suggested Data and Code Availability Statement

The analysis scripts, locked 13-gene signature, model hyperparameters, source data tables for the revised figures, and processed validation summaries have been deposited in a public GitHub repository and archived through Zenodo. Raw public datasets used in the study should be accessed from their original repositories or accession records. The deposited materials support reproduction of the 13-gene score calculation, Kaplan-Meier analyses with number-at-risk tables, bootstrap confidence intervals for C-index and time-dependent AUC, GSE13213 EGFR-mutant subset validation, and stage-association analyses. No non-public identifiable patient-level information is included in the repository.
